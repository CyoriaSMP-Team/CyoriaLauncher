# Migration and attribution

CyoriaLauncher was created as a unified Desktop + Mobile repository.

Source snapshots:

- Mobile: https://github.com/CyoriaSMP-Team/CytechLauncher
- Desktop: https://github.com/CyoriaSMP-Team/CyoriaLauncher-Desktop

The original repositories remain the historical source of their commit history, releases and contributor attribution. This monorepo starts a new integration history from the migrated snapshots; it does not claim authorship of work recorded in the original repositories.

## Layout mapping

- `CytechLauncher` repository → `mobile/`
- `CyoriaLauncher-Desktop` repository → `desktop/`

Future shared contracts and sync-related code belong under `shared/`.
